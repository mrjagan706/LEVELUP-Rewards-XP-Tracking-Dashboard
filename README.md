# VELOOP Rewards – Level-Up Dashboard (Task 16)
React + Vite + Bootstrap + CSS Modules + Lucide. **All XP, levels and rewards are demo data** (see `src/data/data.js`); progress persists in localStorage.

## Run (Windows / VS Code)
1. Install Node.js LTS, open this folder in VS Code, open a terminal (Ctrl+`).
2. `npm install` then `npm run dev` (open the URL shown). `npm run build` for production.

## Deploy (Vercel)
Push to GitHub, import in Vercel (framework: Vite). `vercel.json` rewrites `/Lvl-Dashboard` to the app.

## Features
Level hero + XP bar, next-level locked reward, level roadmap, XP Catcher mini-game (20s, 3 plays/day, demo rewards), Earn More XP cards (one-time/daily claims, Coming Soon for Watch & Refer), XP history with empty state, loading skeleton, error state (`?error=1`), level-up modal, info tooltips.
